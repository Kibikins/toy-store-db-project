This project creates a PostgreSQL database from CSV files. 

The dataset consist of the following files: 
  products
  orders
  order_items
  order_item_refunds
  website_sesions
  website_pageviews

The database is called 'toydb'. 

Entity Relationship Diagram: toydb-toy_store-erd.svg

There are 2 sql files: schema and create-tables. 

There is one python file called load-psql-tables.
